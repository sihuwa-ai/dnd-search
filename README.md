Because Android Chrome needs a live URL to bookmark, host it on a free static host:

GitHub Pages (Permanent & Reliable)

o Create a free account on GitHub.com.

o Create a new repository named dnd-search (set to Public).

o Click Add file > Create new file, name it index. html , and paste the code above.

o Go to Settings > Pages > select branch main > Save.

o GitHub will give you a free live URL 
(e.g.,
   [https://yourusername.github.io/dnd-search/]
   (https://yourusername.github.io/dnd-search/)
